# 安全に関する注意事項

## このアプリについて

**Emotion-Aware Control Chat は、医療診断・治療・カウンセリングではありません。**

このアプリは、自己整理・メタ認知・意思決定支援のための実験的ツールです。
AIが提供する分析・回答は、あくまでも情報提供であり、専門家の判断に代わるものではありません。

---

## 危機的な状況にある場合

以下のような状態にある場合は、このアプリではなく、専門機関・緊急窓口にご相談ください。

- 自分を傷つけたい気持ちがある
- 死にたい・消えたいという気持ちが続いている
- 他者への危害を考えている
- 日常生活・仕事・睡眠・食事が著しく困難になっている
- 強い恐怖・パニック・解離症状がある

## AIへの過度な依存を避けること

このアプリは、不安の構造化・自己観察を支援するためのツールです。
しかし、AIとの対話がすべての問題を解決するわけではありません。

以下の点に注意してください：

- **AIの回答は参考情報です。** 最終的な判断はあなた自身が行ってください。
- **長期的なメンタルヘルスの問題には、専門家のサポートが必要です。**
- **アプリの利用が義務感・依存感になっている場合は、利用を一時停止してください。**
- **信頼できる人間（家族・友人・同僚）への相談を、AIより優先してください。**

## データとプライバシー

このアプリはローカルで動作するプロトタイプです。

- チャット履歴はブラウザのセッション内にのみ保存されます
- セッションを閉じると履歴は消えます
- JSONエクスポートをした場合、そのファイルはあなたのローカルに保存されます
- OpenAI APIを使用する場合、入力内容はOpenAIのAPIに送信されます。OpenAIのプライバシーポリシーをご確認ください。
