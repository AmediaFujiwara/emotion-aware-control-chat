# 回答方針マッピング

## 単軸パターン

### 境界侵害優位（Boundary Violation ≥ 5、他軸 < 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 役割・責任範囲・時間・作業範囲を明確化する |
| 副方針 | どこまで自分がやるべきかを整理する |
| 避けること | すぐ全部引き受けさせる、追加作業を増やす、相手の期待を過剰に読ませる |
| 回答スタイル | 範囲確認を優先。確認文の例を提示する。 |
| NI候補 | 担当外の作業を今日は引き受けない |

**典型的な回答の構造：**
1. 「現在、○○が自分の担当範囲に侵入している状態です」
2. 「自分がやるべきことと、やらなくてよいことを分けます」
3. 「今日の確認アクション：○○さんへの範囲確認メッセージを送る」

---

### 制御不能優位（Uncontrollability ≥ 5、他軸 < 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 制御可能なものと制御不能なものを分ける |
| 副方針 | 今やれる最小行動に縮小する |
| 避けること | 相手の気持ちを断定する、未来予測を深掘りする、答えの出ない推測を続けさせる |
| 回答スタイル | 扱えるもの/扱えないものをリスト化。今日の一手に絞る。 |
| NI候補（スコア ≥ 7） | 相手の評価・会社の方針・市場動向を今日は考えない |

**典型的な回答の構造：**
1. 「今気になっていることの多くは、自分では直接変えられないものです」
2. 「今日自分が扱えること：○○。扱えないこと：○○」
3. 「今日の最小行動：○○だけをやる。それ以外は今日は手放す」

---

### 予期的喪失優位（Anticipated Loss ≥ 5、他軸 < 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 未来の損失予測と現在の事実を分ける |
| 副方針 | 守るべきものを具体化し、最悪ケースと回復可能性を分ける |
| 避けること | 根拠なく大丈夫と言う、未来不安を否定する、破局予測を拡大する |
| 回答スタイル | 今起きていること vs まだ起きていないことの分離 |
| NI候補（スコア ≥ 8） | まだ起きていない損失予測を今日は扱わない |

**典型的な回答の構造：**
1. 「今不安に感じていることの多くは、まだ起きていない将来の予測です」
2. 「今起きている事実：○○。まだ起きていないこと：○○」
3. 「今日守るもの：○○。今日はそれだけに絞る」

---

## 複合パターン

### 境界侵害 + 制御不能（両方 ≥ 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 境界設定と論点の限定 |
| 副方針 | 制御不能な納得追求を止める |
| NI | 推奨（should_use_ni = true） |
| NI理由 | 相手の完全な納得は制御不能。無限対応を止める必要がある |

**典型的な状況：**
- 上司・同僚・取引先から過剰な説明・対応・確認を要求されている
- 相手がどう思うかわからないのに、完璧に納得させようとしている

**回答の方向：**
- 「確認済みの事実」と「相手の判断に委ねる点」を分ける
- 「今日中の完全解決」を手放す
- 相手への確認文を1つ提案する

---

### 制御不能 + 予期的喪失（両方 ≥ 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 未来予測から距離を取り観測に留める |
| 副方針 | 制御可能な今日の一点に縮小する |
| NI | 推奨（should_use_ni = true） |
| NI理由 | 会社方針・将来評価など制御不能な対象に向かっている。今は扱わない |

**典型的な状況：**
- 会社の方向性や自分の将来の評価・役割が見えない
- 努力しても結果が読めず、将来への不安が大きい

**回答の方向：**
- 「会社の方針」「相手の評価」「将来の役割」は自分では決められないことを明確化
- 今週・今日・次の一手に縮小
- 長期予測・結論は今日は出さない

---

### 境界侵害 + 予期的喪失（両方 ≥ 5）

| 項目 | 内容 |
|---|---|
| 主方針 | 境界を守りながら失うかもしれないものを具体化する |
| 副方針 | 未来の損失予測と現在の事実を分ける |
| NI | 状況に応じて検討 |

**典型的な状況：**
- 仕事・人間関係への過剰対応を続けることで、自分を守るものを失いそうになっている

---

## 三軸高負荷パターン（全軸 ≥ 7 または合計 ≥ 21）

これは最も高負荷な状態です。通常の問題解決アプローチは逆効果になります。

| 項目 | 内容 |
|---|---|
| 主方針 | 介入を減らし安全と安定を確認する |
| 副方針 | 解決策より負荷低減を優先する |
| 避けること | タスク列挙、努力の促進、長い分析、行動の追加 |
| NI | 強く推奨（should_use_ni = true） |
| 回答の長さ | 短く（200〜300字以内） |

**回答の方向：**
- 「今日は解決ではなく安定化」
- 「大きな判断をしない」
- 水分を取る、横になる、下書きだけにするなど身体負荷を下げる提案
- 必要なら専門機関・緊急相談への誘導
