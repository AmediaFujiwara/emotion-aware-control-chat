# Axis Definitions（3軸定義）
<!-- spec-id: SPEC-AX -->

このドキュメントが3軸の定義・スコアリング基準・キーワードの **Single Source of Truth（唯一の正典）** です。  
軸定義を変更した場合は、以下の関連ファイルをすべて更新してください（traceability_matrix.md参照）。

---

## SPEC-AX-01：Boundary Violation / 境界侵害

### 定義
本来守られるべき生活・回復・思考・役割・時間・責任範囲に、仕事・他者・評価・義務・期待などが侵入している状態。

### スコアを上げる状態
- 自分の担当範囲ではない作業が流れ込んでくる
- 休むべき時間・私生活に仕事や他者が侵入する
- 無限に説明・対応・確認を求められている
- 役割外の作業を断れずに引き受けている
- 自分の境界線（バウンダリー）が曖昧になっている
- プライベートな時間・空間が仕事によって壊されている

### フォールバックキーワード（`utils/fallback_rules.py:BOUNDARY_KEYWORDS`）

```python
BOUNDARY_KEYWORDS = [
    "侵入", "境界", "責任", "役割", "どこまで", "押し付け", "巻き込まれ",
    "休めない", "説明しないといけない", "無限に", "曖昧な依頼", "全部自分",
    "私生活", "プライベート", "時間外", "仕事が入ってくる", "頼まれた",
    "やらされ", "断れない", "範囲", "限界", "過剰", "自分のことなのに",
    "自分の時間", "休息", "睡眠が取れない", "業務外", "勝手に",
]
```

### 対応する応答方針（SPEC-RP-02参照）
- 役割・責任範囲・時間・作業範囲を明確化する
- 確認文の例を提案する
- 境界に侵入されている構造を言語化する

## SPEC-AX-02：Uncontrollability / 制御不能性

### 定義
その問題が、自分の努力や行動で制御できるか、あるいは他者・組織・市場・未来・病気・制度など外部要因に支配されているかを示す。

### スコアを上げる状態
- 相手がどう考えるかわからない
- 組織・会社の方向性・判断が読めない
- 何をすれば問題が終わるかわからない
- 自分では変えられない要素を延々と考えている
- 将来の変化・市場・制度の動向が制御できない
- 他者の意思決定・反応・評価に依存している

### フォールバックキーワード（`utils/fallback_rules.py:UNCONTROLLABILITY_KEYWORDS`）

```python
UNCONTROLLABILITY_KEYWORDS = [
    "わからない", "相手次第", "判断次第", "制御できない", "どうなるか",
    "読めない", "変えられない", "終わらない", "納得しない", "会社の方針",
    "市場", "未来", "決まらない", "不確か", "振り回され", "誰が決める",
    "どうしたら", "どうすれば", "見通しがない", "予測できない", "相手が",
    "上司が", "組織が", "制度が", "どうなるかわからない", "どこに向かうか",
]
```

### 対応する応答方針（SPEC-RP-03参照）
- 制御可能なものと制御不能なものを分ける
- 今やれる最小行動に縮小する
- 答えの出ない推測を続けさせない
- スコア≥7でNI推奨

## SPEC-AX-03：Anticipated Loss / 予期的喪失

### 定義
将来において失われるかもしれないものを先取りして不安になる状態。失われる対象は、評価・健康・生活・家族関係・仕事・将来の安定・自己効力感など。

### スコアを上げる状態
- 評価が下がるかもしれない
- 立場が悪くなるかもしれない
- 生活・家族関係・健康が崩れるかもしれない
- 取り返しがつかないことになるかもしれない
- 今後ずっと不利になるかもしれない
- 将来が見通せないという恐怖

### フォールバックキーワード（`utils/fallback_rules.py:ANTICIPATED_LOSS_KEYWORDS`）

```python
ANTICIPATED_LOSS_KEYWORDS = [
    "失う", "評価が下がる", "立場が悪くなる", "崩れる", "怖い", "将来",
    "生活", "健康", "家族", "取り返しがつかない", "不利になる",
    "失職", "クビ", "終わり", "壊れる", "失敗したら", "もし", "破綻",
    "信頼を失う", "大切なもの", "守れない", "なくなる", "消える",
    "いなくなる", "ダメになる", "挽回できない", "後悔", "手遅れ",
]
```

### 対応する応答方針（SPEC-RP-04参照）
- 未来の損失予測と現在の事実を分ける
- まだ起きていないことを事実として扱わない
- スコア≥8でNI推奨

## SPEC-AX-04：スコアリングアルゴリズム（フォールバックモード）

フォールバックモードにおけるスコア算出方法。LLMモードでは LLM が独自に判断する。

### 算出ステップ

1. テキスト中の各軸キーワードの出現数をカウント（`_count_keywords`）
2. カウントをスコアに変換（`_score_from_count`）

```python
def _score_from_count(count: int, max_count: int = 5) -> int:
    ratio = min(count / max_count, 1.0)
    return round(ratio * 10)
```

| キーワード数 | スコア |
|---|---|
| 0 | 0 |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |
| 5以上 | 10 |

3. 入力が20文字以上かつ全軸0の場合、最小ベースライン `bv=uc=al=2` を設定（チャート描画のため）

### 変更影響
`max_count` を変更 → スコア感度が変わる → チャートの見た目が変わる  
→ `utils/fallback_rules.py:_score_from_count` を変更
