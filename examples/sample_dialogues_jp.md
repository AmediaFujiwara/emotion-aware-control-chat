## 例1：境界侵害が強い例

**ユーザー入力：**
> 最近、仕事が休日も頭から離れない。上司から土日もSlackで連絡が来て、断れない雰囲気がある。自分の責任範囲じゃないことまで全部自分が引き受けないといけない気がしてきた。

**予想されるスコア：**
- 境界侵害: 8
- 制御不能性: 4
- 予期的喪失: 3

**AIの回答方針：** 役割・責任範囲の明確化、範囲確認の文例提示

**期待される回答の方向：**
```
休日の連絡と、担当外の業務が自分の空間に侵入している状態です。
今何より必要なのは「解決」よりも「範囲の確認」です。

境界：
- 自分の担当範囲：○○（今日の業務）
- 今日は受け取らないもの：担当外の作業依頼

今日の確認アクション：
「○○の件は、私の担当範囲で対応できる部分は△△です。
それ以外については、□□さんにご確認いただけますか？」という一文を用意するだけでよいです。

今日は全部解決しなくてよい。範囲を決めることが安定化への一歩です。
```

## 例2：制御不能性が強い例

**ユーザー入力：**
> 来月の評価面談のことが気になって、上司が自分をどう見ているかわからなくて不安。最近ミスがあったから評価が下がるかもしれない。でもどうすれば上司が納得するかわからないし、会社の方針も読めない。

**予想されるスコア：**
- 境界侵害: 3
- 制御不能性: 8
- 予期的喪失: 6

**AIの回答方針：** 制御可能/不可能の分離、今日の最小行動に縮小、NI推奨

**期待される回答の方向：**
```
今気になっていることの多くは、自分では直接変えられない領域にあります。

扱えること（今日）：
- ミスの内容と再発防止策を1行メモする
- 面談で伝えたい点を箇条書きにする

扱えないこと（今日は考えない）：
- 上司の評価・内心
- 会社全体の方針
- 来月の面談結果

NI候補：
「上司の評価を今日中に把握しようとしない」

今日の最小行動：
ミスについての事実だけを3行でメモする。それだけでよいです。

今は観察に留める。答えのない推測を続けると消耗します。
```

## 例3：予期的喪失が強い例

**ユーザー入力：**
> 最近、健康診断の結果が少し悪くて、このまま生活が崩れていくんじゃないかと怖い。評価も下がりそうだし、家族との関係も最近うまくいっていないし、何かが少しずつ崩れていく感じがする。

**予想されるスコア：**
- 境界侵害: 3
- 制御不能性: 5
- 予期的喪失: 8

**AIの回答方針：** 現在の事実と未来予測の分離、守るものの具体化

**期待される回答の方向：**
```
将来に向けて、様々なものを失うかもしれないという不安が重なっている状態です。
ただ、今不安に感じていることの多くは、まだ起きていないことです。

今起きていること（事実）：
- 健康診断の結果が基準値を超えた項目がある
- 家族との会話が少なくなっている

まだ起きていないこと（今日は扱わない）：
- 生活全体の崩壊
- 長期的な評価の低下
- 家族関係の破綻

今日守るもの（具体的に1つ）：
今日は「健康診断の結果をかかりつけ医に見せる予約をする」だけを実行する。

将来全体ではなく、今日の一点だけを守ることが安定化につながります。
```

## 例4：境界侵害 + 制御不能性が強い例

**ユーザー入力：**
> 上司から無限にメールで確認が来る。返しても返しても次の質問が来て、何をすれば終わるのかわからない。相手が何に納得していないかもわからないし、どこまで対応すれば十分なのかも決まっていない。

**予想されるスコア：**
- 境界侵害: 8
- 制御不能性: 8
- 予期的喪失: 4

**AIの回答方針：** 境界設定 + 論点限定、NI推奨（無限対応を止める）

**期待される回答の方向：**
```
自分の対応範囲に、相手の納得基準が不明確なまま無限に侵入している状態です。

確認済みの事実：
- 送付した内容は○○（記録あり）
- 今日対応した確認事項は△△件

今日これ以上やらないこと（NI）：
- 相手が何に納得していないかを深掘りしない
- 今日中の完全解決を目指さない

投げ返す確認文（提案）：
「いただいたご確認について、○○と△△については回答済みです。
上記以外にご確認されたい具体的な点があれば教えていただけますか？」

今日の最小行動：
この確認文を下書きだけにする（送るかどうかは明日判断する）。

相手の完全な納得は今日は取りにいかない。これが今日の安定化方針です。
```

## 例5：制御不能性 + 予期的喪失が強い例

**ユーザー入力：**
> 会社の組織変更がありそうで、自分の部署がどうなるかわからない。評価が下がれば立場が悪くなる可能性もあるし、将来の収入にも影響するかもしれない。何もできないまま、状況が悪い方向に進んでいくんじゃないかと怖い。

**予想されるスコア：**
- 境界侵害: 2
- 制御不能性: 8
- 予期的喪失: 8

**AIの回答方針：** 未来予測から距離を取る、観測に留める、NI強く推奨

**期待される回答の方向：**
```
組織変更という制御できない変化に、将来の損失予測が重なっている状態です。

扱えないもの（今日は考えない）：
- 会社の組織変更の方向性
- 将来の評価・収入・立場への影響

今日扱えること：
- 今日の業務を通常通りこなす
- 自分の実績・成果を1行メモしておく

NI候補：
「会社全体の方針予測を今日はしない」
「収入・立場への長期的影響を今日は計算しない」

今日の最小行動：
今日の業務で自分がやったことを1行だけ書く。それが今日の記録になります。

結論は今日出さなくてよい。状況を観察するだけが今日の方針です。
```

## 例6：三軸すべて高い例

**ユーザー入力：**
> もう何もかもがわからなくなってきた。仕事は終わらないし、上司にも同僚にも何か言われそうで怖い。家族にも迷惑をかけているし、このまま全部崩れていくような気がする。毎日が重くて、もう休みたいというか消えたい気持ちもある。

**予想されるスコア：**
- 境界侵害: 8
- 制御不能性: 9
- 予期的喪失: 9

**AIの回答方針：** 三軸高負荷 → 介入を減らす、安定化優先、身体回復、安全確認

**期待される回答の方向：**
```
今、非常に高い負荷がかかっている状態です。
解決より安定を優先します。

今日は大きな判断をしないでください。
仕事・人間関係・将来の不安を今日すべて解決しようとしないでください。

今日の最小行動：
水分を取って、10分だけ横になる。それだけでよいです。

---
⚠️ 「消えたい」という気持ちについて：
今すぐ一人で抱えないでください。
信頼できる人に連絡する、または以下にご相談ください。
よりそいホットライン：0120-279-338（24時間）

今日は「安全でいること」だけが方針です。
```

*これらのサンプル対話は、LLMモードでの実際の出力とは異なる場合があります。*
